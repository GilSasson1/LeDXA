# Supplementary data tables

Machine-readable data for the Supplementary Tables of the LeDXA manuscript. One file per
table, named by its Supplementary Table number. Each is the **complete** table: every row
and every value in its own column, including unadjusted *P* values and the raw analysis
identifiers, where the typeset appendix may show a summary. The full legends are in the
manuscript's Supplementary Information.

Generated by `supplement/build_supplementary_tables.py` — do not edit by hand.

## Plotting inputs are not shipped

The `plotting/` scripts read intermediate per-arm, per-seed and pairwise-significance tables that
are deliberately not distributed; each script names the environment variable that points at a local
copy. A `tables/figure_inputs/` directory used to hold two of them and was removed on 2026-08-03: a
partial set is worse than none, because those copies had drifted from the run behind the published
figures, so anyone running the scripts would have obtained panels disagreeing with the paper.

The `TableS*.csv` files above are the authoritative published form of every number. Regenerating a
figure end-to-end additionally needs controlled cohort data (see the repository README) - the
plotting code is a reference implementation of how the statistics become the published panels.
