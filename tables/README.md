# Supplementary data tables

Machine-readable data for the Supplementary Tables of the LeDXA manuscript. One file per
table, named by its Supplementary Table number. Each is the **complete** table: every row
and every value in its own column, including unadjusted *P* values and the raw analysis
identifiers, where the typeset appendix may show a summary. The full legends are in the
manuscript's Supplementary Information.

Generated by `supplement/build_supplementary_tables.py` — do not edit by hand.

## `figure_inputs/` — not supplementary tables

Internal-schema copies that the figure scripts read and write. They hold the same statistics as
the tables above but keep the raw analysis column names and the abbreviated disease labels used
as figure axis ticks, so the plotting code is not coupled to publication formatting. For any use
other than regenerating a figure, read the `TableS*.csv` files.

| File | Used by | Published form |
|---|---|---|
| `fig2_hpp_disease.csv` | read by `plotting/fig2_heatmap.py` | Table S2 |
| `fig2_ukbb_disease.csv` | read by `plotting/fig2_heatmap.py` | Table S3 |
| `fig3_incident_disease.csv` | written by `plotting/fig3_cox.py` (git-ignored) | Table S5 |

The figure scripts also read per-seed and pairwise-significance tables that are not distributed;
each script names the environment variable to point at its own copy. Regenerating a figure
end-to-end additionally needs controlled cohort data (see the repository README) — the plotting
code is a reference implementation of how the statistics become the published panels.
